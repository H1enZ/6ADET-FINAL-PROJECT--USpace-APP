# USpace — Demo Video

**Project:** USpace — A Private App for Couples  
**Live application:** [Open USpace](https://h1enz.github.io/USpace/)  
**Demo recording:** [Watch on Google Drive](https://drive.google.com/drive/folders/1xLpXpmEgaxzFTsB-vuYS3_B-xGaInN48?usp=sharing)  
**Target duration:** 3–5 minutes  
**Recording platform:** Desktop browser

---

## 1. Demo Accounts and Privacy

The demonstration uses **Tester A** and **Tester B**, the two accounts listed in the [README — Tester Accounts](../README.md#tester-accounts). Both accounts are already paired as one couple in the live application.

All demo content is fictional. It includes made-up names, sample conversations, and illustrations created for the project (sunsets, a beach, a city skyline, and flowers). **No real people's faces, private messages, or personal data are shown.**

## 2. Prepared Demo Data

| Feature | Content prepared for the demonstration |
| :--- | :--- |
| **Timeline** | Six memories with one or two photos each, a location, and a tag. Uses Film, Postcard, and Taped frames, plus a yellow sticky note reading *“Best year so far.”* |
| **Moods** | Both partners initially select **Loved**, displaying **“Loved together”** on Home. Different selections appear separately. |
| **Chat** | A short, two-sided sample conversation about a cozy Wednesday night. |
| **Love Notes** | One note under **Missing You**, accompanied by a flower photo. |
| **Time Capsules** | One capsule sealed by Tester A for Tester B, set to unlock on **October 8, 2027**. A new capsule can be created during the demo. |
| **Therabot** | One completed **Couple Reflection**; each partner's responses are private, with a shared reflection generated from short summaries. |
| **Bucket List** | **See the cherry blossoms together** in Kyoto; **₱60,000** budget and **₱15,000** in recorded savings. |

## 3. Video Flow and Demonstration Script

| Timestamp | Screen / Feature | Demonstration steps |
| :--- | :--- | :--- |
| **0:00** | **Introduction** | Introduce USpace as a private space for two people in a relationship, including long-distance couples. |
| **0:20** | **Sign In & Pairing** | Sign in as Tester A. Show how an invite code connects two accounts into one couple. |
| **0:50** | **Home & Moods** | Choose a mood as Tester A. Switch to Tester B and choose a different mood to show separate states; match the moods to show the shared state. Add a note. |
| **1:30** | **Chat** | Send a message and a reaction in one browser. Show both appearing for the other partner without refreshing. |
| **2:00** | **Timeline** | Show the scrapbook corkboard, Polaroid-style photos, tape, and support for up to 10 photos per memory. Use the pencil to rearrange memories. Add a memory with photos, a story, a place, and a tag. |
| **2:50** | **Love Notes** | Write a categorized note. Open it from the other account to demonstrate the paper-letter design. |
| **3:20** | **Time Capsules** | Create and seal a capsule with a photo and unlock date. Explain that its contents remain unavailable until that date. |
| **3:50** | **Therabot** | Demonstrate **Private Talk** and **Reflect Together**. Have each tester answer a reflection question privately. |
| **4:20** | **Bucket List** | Show the feature I personally coded: add a goal and location, set a budget, record savings, and mark it complete. |
| **4:45** | **Closing** | Summarize USpace's privacy approach, including database-enforced access restrictions for couple data. |

## 4. Closing Statement

> USpace is more than a messaging app. It's a private space where couples can preserve memories, share feelings, plan experiences, and stay connected even when they're physically apart.
